# TradeX - Trading Platform

A comprehensive trading platform built with modern web technologies to provide users with tools for buying and selling stocks, cryptocurrencies, and other financial instruments.

## 🎯 Overview

TradeX is a full-stack trading platform that combines a powerful backend with an intuitive frontend and administrative dashboard. The platform enables users to execute trades, monitor portfolios, and track market data in real-time.

## 📁 Project Structure

```
TradeX--Trading-Platform/
├── backend/          # Backend API and server logic
├── frontend/         # Main user-facing trading interface (Vite + React)
├── dashboard/        # Administrative dashboard (Vite + React)
└── README.md        # This file
```

## 🛠️ Technology Stack

### Languages
- **React.js** - A frontend JavaScript library used for building interactive user interfaces.
- **JavaScript** - Primary language for frontend and backend (84,809 bytes)
- **HTML** - Markup for web interfaces (1,367 bytes)
- **CSS** - Styling and layout (32,251 bytes)

### Architecture
- **Frontend**: Vite + React for the main trading interface
- **Backend**: Node.js/Express server for API endpoints
- **Dashboard**: Vite + React for administrative management

## 🚀 Features

- **Trading Interface**: Intuitive UI for executing trades
- **Portfolio Management**: Track and manage your investments
- **Market Data**: Real-time market information and analytics
- **Admin Dashboard**: Platform management and monitoring
- **Responsive Design**: Works seamlessly on desktop and mobile devices

## 🔧 Getting Started

### Prerequisites
- Node.js and npm installed
- Git for version control

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Maddy74/TradeX--Trading-Platform.git
   cd TradeX--Trading-Platform
   ```

2. **Backend Setup**
   ```bash
   cd backend
   npm install
   # Configure environment variables
   npm start
   ```

3. **Frontend Setup**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

4. **Dashboard Setup**
   ```bash
   cd dashboard
   npm install
   npm run dev
   ```

## 📋 Available Scripts
